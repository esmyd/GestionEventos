## Opción A: Paquete completo - Todo incluido

### Precio total año 1: **$6,500**

Incluye:
- **Licencia anual** del sistema con TODOS los módulos activos
- **Hosting y dominio** el primer año
- **Mantenimiento** el primer año (soporte, actualizaciones menores)
- **Capacitación inicial** (2 sesiones de 1 hora)
- **Migración de datos** (hasta 100 clientes y 50 eventos)

### Módulos incluidos

| Categoría | Módulos |
|-----------|---------|
| **Core** | Eventos, Clientes, Productos, Planes, Salones, Categorías, Pagos, Calendario |
| **Reportes** | Básicos y avanzados, exportación Excel/PDF |
| **Inventario** | Control de stock, disponibilidad por fecha |
| **WhatsApp** | Chat bidireccional, Bot de respuestas, Plantillas, Métricas |
| **Comunicación** | Notificaciones email, Notificaciones internas |
| **Integración** | Portal del cliente, Carga masiva |
| **Administración** | Gestión de usuarios, Roles y permisos |

### Ideal para
Empresas que quieren la solución completa desde el día uno, sin elegir módulos.

## Opción B: Personalizable - Por módulos

### Estructura de precios

#### 1. Módulo base (obligatorio - MVP)

| Módulo | Precio anual | Descripción |
|--------|--------------|-------------|
| **Eventos + Catálogos + Reportes** | **$3,700** | Mínimo viable para operar |

**Incluye:**
- Gestión de eventos (crear, cotizar, confirmar, seguir estados)
- Catálogo: Productos, Planes/paquetes, Salones, Categorías
- Gestión de clientes
- Registro de pagos y abonos
- Reportes básicos (ingresos, pendientes, eventos)
- Dashboard con resumen
- Generación de cotización y contrato en PDF

**Dependencias:** Ninguna. Es el núcleo del sistema.

---

#### 2. Módulos adicionales (independientes)

Estos módulos se pueden agregar o quitar según necesidad. Son **independientes** entre sí.

| Módulo | Precio anual | Descripción |
|--------|--------------|-------------|
| **Inventario** | $580 | Control de stock, reservas por evento, disponibilidad por fecha |
| **WhatsApp (plataforma)** | $980 | Chat bidireccional, Bot automático, Plantillas, Inbox, Métricas |
| **Portal del cliente** | $480 | El cliente ve su evento, saldo y confirma detalles desde web/cel |
| **Calendario** | $370 | Vista calendario de eventos, disponibilidad de salones |
| **Notificaciones automáticas** | $420 | Email y WhatsApp: evento creado, recordatorios, saldo pendiente |
| **Carga masiva** | $220 | Importar clientes, productos o eventos desde Excel/CSV |
| **Gestión de usuarios** | $320 | Múltiples usuarios (admin, coordinador, gerente), roles y permisos |

---

#### 3. Dependencias entre módulos

| Módulo | Requiere | Nota |
|--------|----------|------|
| Base (Eventos + Catálogos) | — | Obligatorio |
| Inventario | Base | Productos deben existir |
| WhatsApp | Base | Para vincular a clientes/eventos |
| Portal del cliente | Base | Muestra eventos del cliente |
| Calendario | Base | Muestra eventos |
| Notificaciones | Base | Disparadas por eventos |
| Carga masiva | Base | Importa a catálogos/eventos |
| Gestión de usuarios | Base | Usuarios acceden al sistema |

**Regla:** No se puede contratar un módulo sin tener el base. Entre módulos adicionales no hay dependencias cruzadas.

## Opción D: Compra del código fuente - Plataforma propietaria

### Precio total: **$9,900** (pago único)

Incluye:
- **Entrega del código fuente** (frontend, backend, base de datos)
- **Implementación completa:** Hosting año 1 ($350-$450), Dominio ($15-$25), Plantilla/música ($250), Codificación e implementación ($900), Ajustes de la empresa ($500), Carga de información y configuración ($600)
- **Capacitación** (2 sesiones de 1 hora)
- **Documentación técnica** y de usuario
- El **código es propiedad de Siglo Tecnológico**; el cliente recibe licencia perpetua de uso. La **información en la base de datos es 100% del cliente**

### Qué reciben

- Código fuente (frontend + backend + base de datos)
- Acceso a repositorio o entrega de archivos
- Esquema de base de datos
- Guías de instalación y despliegue

### NO incluye (a partir de la entrega)

- Mantenimiento
- Actualizaciones
- Nuevos módulos futuros
- Soporte técnico (se puede contratar aparte)

### Ideal para

Empresas que quieren ser dueñas del sistema, tener control total, evitar dependencia del proveedor o planear modificaciones a largo plazo.

### Costos posteriores

- Hosting y dominio: ~$150-200/año
- Mantenimiento (opcional): cotización aparte
- WhatsApp Business API: ~$60/mes
