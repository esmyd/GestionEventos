Condiciones generales y propiedad

Propiedad intelectual y datos: El código fuente, la plataforma y todo el software desarrollado son propiedad de Siglo Tecnológico. La información del cliente almacenada en la base de datos (clientes, eventos, pagos, productos, etc.) es propiedad exclusiva del cliente. Siglo Tecnológico no reclama derecho alguno sobre los datos del negocio del cliente.
Servicios de integración y mantenimiento: Las integraciones (WhatsApp Business API, etc.) y el mantenimiento se facturan mensualmente: integraciones $68/mes, mantenimiento $95/mes. No están incluidos en la licencia (excepto mantenimiento año 1 en Opción A).

Condiciones para la implementación

  • El cliente debe proveer: acceso a datos actuales (Excel, lista de clientes/productos), logo y datos de contacto.
  • La implementación estándar incluye configuración inicial, carga de catálogo base y capacitación.
  • Personalizaciones fuera del alcance estándar se cotizan aparte.
  • Los plazos de implementación se acuerdan según la opción elegida y disponibilidad.
